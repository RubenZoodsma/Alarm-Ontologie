MDA · ontology project

Medical Device Alarm

An ontology, a controlled vocabulary and a set of example knowledge graphs for representing medical device alarms — the technical chain that produces an alarm (device, sensor, signal, metric) and the clinical and therapeutic meaning it implies.

Resources

Ontology →

The formal model — classes and properties, with definitions, axioms and a class hierarchy. Generated reference documentation.
Vocabulary →

The controlled terms that fill the model in — manufacturers, device types, physiological properties, organs — browsable and searchable, in English and Dutch.
Knowledge Graphs →

One alarm type at a time: every fact a reasoner derives from it, as a diagram and a fact table, with a searchable ontology glossary alongside it.
Data →In progress

Raw exportable files for the vocabulary and example knowledge graphs. Not published yet.
Competency Questions →

Every competency question the ontology has been tested against — the natural-language question, the SPARQL that answers it, and the results it actually returns.

Persistent identifiers for these resources resolve through w3id.org/mda/ — e.g. w3id.org/mda/ontology# for the ontology itself.
